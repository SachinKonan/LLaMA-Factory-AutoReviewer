# Alignment Analysis

## Overview

This analysis measures whether AI-generated paper improvement suggestions are aligned with human reviewer suggestions. We compare suggestions from Gemini 2.5 Flash (conditioned on the text model's accept/reject prediction) against suggestions extracted from ground truth ICLR reviews, graded using LLM-as-judge on metareview annotations.

---

## Research Question

**Does conditioning Gemini's suggestion generation on the model's prediction (accept/reject + confidence) produce suggestions that better align with what human reviewers actually flagged?**

Alignment is measured by comparing:
- **AI suggestions**: generated by Gemini 2.5 Flash, conditioned (or not) on the text model's prediction
- **Human suggestions**: extracted from ground truth reviewer comments

## Pipeline Steps

### 1. Extract human suggestions from ground truth reviews
- For each paper in the 500-paper subset, parse `original_reviews` to extract per-reviewer suggestions as a sequence of discrete claims.
- Each reviewer's suggestions are stored separately (per-reviewer, per-paper).

### 2. Update inference to output prediction + confidence
- Modify the text model inference script to return:
  - Binary decision: `Accept` or `Reject`
  - Logit confidence: the raw logit score for the predicted class

### 3. Generate Gemini suggestions (two variants)
Run two separate Gemini inference jobs, each producing **5 suggestions per paper**:

- **Conditioned variant**: Gemini receives the paper content + the model's prediction (accept/reject) and confidence score
- **Unconditioned baseline**: Gemini receives the paper content only (no prediction signal)

### 4. Grade alignment using LLM-as-judge
Use Gemini to compare AI suggestions vs. human suggestions, graded against metareview annotations. Compute the following metrics per paper:

| Metric | Description |
|--------|-------------|
| **Intersection count** | # of suggestions present in both AI and human sets |
| **Human coverage** | Fraction of human suggestions covered by AI suggestions |
| **AI coverage** | Fraction of AI suggestions covered by human suggestions |
| **Unrelated AI suggestions** | # of AI suggestions with no correspondence to any human suggestion |
